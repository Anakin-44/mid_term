Data Mining
Unit IV: Mining Association Rules in Databases

Unit IV Map: Association basics → Apriori (single-dimensional Boolean) → Multilevel → Multidimensional → Correlation analysis.

1. Association Rule Mining

Finds frequent patterns and relationships among items in transaction data, e.g. buys(milk) → buys(bread) [support 2%, confidence 60%].

Measure Formula
Support(A⇒B) P(A∪B) = transactions containing A and B / total transactions
Confidence(A⇒B) P(B|A) = support(A∪B) / support(A)
  • Strong rule: satisfies both minimum support and minimum confidence.
  • Frequent itemset: support ≥ min_sup. Process: (1) find frequent itemsets, (2) generate strong rules from them.

2. Mining Single-Dimensional Boolean Association Rules (Apriori)

Apriori property: every subset of a frequent itemset must also be frequent (equivalently, if an itemset is infrequent, all its supersets are infrequent). 

 Scan DB -> C1 -> prune < min_sup -> L1
 Join L1 x L1 -> C2 -> scan -> prune -> L2
 Join L2 x L2 -> C3 -> prune by Apriori property -> scan -> L3 ... stop when Lk empty

Solved Example (min_sup = 2 transactions)

TID Items
T1 A, B, C
T2 A, C
T3 A, D
T4 B, E
Step Result
C1 counts A:3, B:2, C:2, D:1, E:1
L1 A, B, C (D, E dropped)
C2 counts AB:1, AC:2, BC:1
L2 {A,C}; no C3, stop
Rule A⇒C confidence = 2/3 = 66.7%; C⇒A = 2/2 = 100%
Exam Trap: Confidence is not symmetric: A⇒C and C⇒A differ; support is the same for both.

Improving Apriori

  • Hash-based itemset counting, transaction reduction, partitioning, sampling, dynamic itemset counting.
  • FP-growth: builds a compact FP-tree and mines it without candidate generation (only 2 DB scans).

3. Mining Multilevel Association Rules

Items have concept hierarchies (food → milk → skim milk). Rules at low levels have low support, so use:

Support approach Idea
Uniform support Same min_sup at all levels; simple but misses low-level rules or yields too many high-level ones
Reduced support Lower min_sup at lower levels (most used)
Group-based support Different thresholds for item groups

Watch for redundant rules where a lower-level rule adds nothing beyond its ancestor rule.

4. Mining Multidimensional Association Rules

Rules involving two or more dimensions/predicates: age(X,"20-29") ∧ occupation(X,"student") ⇒ buys(X,"laptop").

  • Inter-dimension rules: no repeated predicate. Hybrid-dimension: some predicates repeat.
  • Quantitative attributes (age, income) are discretized (static, dynamic or distance-based/clustering).
  • Warehouse cuboids already hold counts, so mining relational DBs and warehouses is efficient.

5. From Association Mining to Correlation Analysis

High support and confidence can still be misleading. Example: of 10,000 transactions, 6,000 buy games, 7,500 buy videos, 4,000 buy both. Rule games⇒videos has confidence 4000/6000 = 66.7%, yet P(videos) = 75% is higher, so the rule is misleading.

Measure Interpretation
lift(A,B) = P(A∪B) / (P(A)·P(B)) >1 positive correlation, =1 independent, <1 negative
χ² test Tests independence of A and B

In the example lift = 0.40 / (0.60 × 0.75) = 0.89 < 1: negatively correlated.
