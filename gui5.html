1. Windows Forms Basics

Core Concept

Windows Forms (WinForms) is the .NET GUI library for desktop apps. A Form is a window; controls (buttons, text boxes) are placed on it. Every control has properties (look), methods (actions) and events (user actions such as Click).

  • Designer: drag-and-drop controls from the Toolbox; the code is generated in Form1.Designer.cs (a partial class).
  • Code-behind: your handlers live in Form1.cs.
  • Naming convention: prefix by type, e.g. textBoxName, btnShowName, labelNameOut.
Exam Trap: (Name) in Properties is the control's identifier in code; Text is the caption the user sees. They are different.

2. TextBox

Displays text and takes user input (typing/pasting).

textBox1.Text = "Bachelor of Computer Applications";
string value = textBox1.Text;
textBox1.Font = new Font("Times New Roman", 12);
textBox1.BackColor = Color.Blue;
textBox1.ForeColor = Color.White;
textBox1.MaxLength = 40;
textBox1.PasswordChar = '*';        // hide typed characters
textBox1.Multiline = true;          // allow several lines
Common properties Common events
Text, Name, Font, BackColor, ForeColor, MaxLength, ReadOnly TextChanged, KeyPress, Enter, Leave

3. RichTextBox

An advanced TextBox that supports RTF formatting (bold, colours, fonts per selection) and multi-line text. 

private void Form1_Load(object sender, EventArgs e)
{
    RichTextBox rtb = new RichTextBox();
    rtb.Location = new Point(20, 20);
    rtb.Size = new Size(300, 200);
    rtb.BackColor = Color.Red;
    rtb.ForeColor = Color.Blue;
    rtb.Font = new Font("Georgia", 16);
    rtb.Text = "Hi! I am pursuing BCA from Invertis University, Bareilly";
    this.Controls.Add(rtb);          // controls must be ADDED to the form
}
Key Concept: A control created in code is invisible until added with this.Controls.Add(control).

4. MaskedTextBox

Restricts input to a fixed format using the Mask property.

Use Mask
Date 00/00/0000
Phone 0000-000-000

0 = required digit; the user cannot type letters where a digit is required.

5. Label and LinkLabel

Label shows text only (no user input). LinkLabel is a label with hyperlink behaviour; it raises the LinkClicked event. 

Label lbl = new Label();
lbl.Text = "User Name";
lbl.Location = new Point(50, 40);
lbl.Font = new Font("Calibri", 16);
lbl.ForeColor = Color.Red;
this.Controls.Add(lbl);

// LinkLabel: open a web page when clicked
private void linkLabel1_LinkClicked(object sender, LinkLabelLinkClickedEventArgs e)
{
    linkLabel1.LinkVisited = true;                       // change to visited colour
    System.Diagnostics.Process.Start(
        new System.Diagnostics.ProcessStartInfo("https://www.example.com") { UseShellExecute = true });
}

6. RadioButton

Select only one option from a group. Radio buttons in the same container (GroupBox or Panel) form one group. Key property: Checked; event: CheckedChanged. 

private void button1_Click(object sender, EventArgs e)
{
    if (radioButton1.Checked) label1.Text = "Selected Gender: Male";
    if (radioButton2.Checked) label1.Text = "Selected Gender: Female";
}
Exam Trap: Radio buttons placed directly on a form all belong to one group. Use separate GroupBox containers for independent groups.

7. CheckBox

Select multiple options at once; each box is independent.

private void button1_Click(object sender, EventArgs e)
{
    string s = "";
    if (checkBox1.Checked) s += checkBox1.Text + ", ";
    if (checkBox2.Checked) s += checkBox2.Text + ", ";
    if (checkBox3.Checked) s += checkBox3.Text + ", ";
    label1.Text = s.Trim().TrimEnd(',');
}
Feature RadioButton CheckBox
Selection One of a group Any number
Grouping By container Independent
Key property Checked Checked (also CheckState for 3-state)

8. ListBox and CheckedListBox

ListBox displays a list; the user selects one or more items. For multi-select set SelectionMode = MultiSimple (or MultiExtended). CheckedListBox shows a check box beside every item. 

private void Form1_Load(object sender, EventArgs e)
{
    listBox1.Items.Add("Kushal Johari");
    listBox1.Items.Add("Mihir Johari");
    listBox1.Items.Add("Naini Johari");
}
private void button1_Click(object sender, EventArgs e)
{
    foreach (string item in listBox1.SelectedItems)
        listBox2.Items.Add(item);                 // copy selected to second list
}

// CheckedListBox: read the ticked items
foreach (object item in checkedListBox1.CheckedItems)
    label1.Text += item.ToString() + " ";
Member Meaning
Items Collection of all items (Add, Remove, Clear)
SelectedItem / SelectedItems Currently selected item(s)
SelectedIndex Index of selection (-1 if none)
CheckedItems (CheckedListBox) ticked items
Exam Trap: You cannot remove items from a collection while looping over it with foreach. Copy to a list first (as the demo form does with ToList()).

9. ComboBox

A drop-down list (TextBox + ListBox combined) that shows one selected item. Common event: SelectedIndexChanged. 

comboBox1.Items.Add("Kushal Johari");
comboBox1.Items.Add("Naini Johari");
comboBox1.Items.Add("Tanvi Johari");
comboBox1.SelectedIndex = 0;                      // preselect first item

private void comboBox1_SelectedIndexChanged(object sender, EventArgs e)
{
    label1.Text = "Selected: " + comboBox1.SelectedItem.ToString();
}
Key Concept: DropDownStyle controls it: DropDown (user can type), DropDownList (choose only), Simple.

10. DateTimePicker and MonthCalendar

DateTimePicker lets the user choose a date/time in a fixed format. MonthCalendar shows a full calendar and supports date ranges. 

private void button1_Click(object sender, EventArgs e)
{
    label1.Text = dateTimePicker1.Value.ToString();
    label2.Text = dateTimePicker1.Value.ToString("dd/MM/yyyy hh:mm tt");
}

// MonthCalendar
label3.Text = monthCalendar1.SelectionStart.ToShortDateString();
// SelectionRange.Start / SelectionRange.End for a range; DateChanged event
Exam Trap: The DateTimePicker's value is in .Value (a DateTime), not .Text. The Format property controls display (Long, Short, Time, Custom).

11. ToolTip

Shows help text when the mouse hovers over a control.

  1. Drag a ToolTip component from the Toolbox onto the form.
  2. Set the tooltip text for a control (property "ToolTip on toolTip1").
  3. Run the app and hover over the control.
toolTip1.SetToolTip(textBoxName, "Enter your name");

12. Shockwave Flash Object

The syllabus lists Shockwave Flash Object: an ActiveX/COM control (added via Toolbox → Choose Items → COM Components) used to play .swf movies inside a form. It is exposed through AxShockwaveFlash and played by setting its Movie property. 

axShockwaveFlash1.Movie = @"C:\media\intro.swf";
axShockwaveFlash1.Play();
Exam Trap: It is a COM (ActiveX) control wrapped for .NET, which links back to the OLE/COM origin in Unit I. Flash is discontinued, so the control is mainly of academic interest.

14.2 OpenFileDialog

Lets the user pick a file; returns the selected path.

private void button1_Click(object sender, EventArgs e)
{
    openFileDialog1.Title = "Select a file";
    openFileDialog1.Filter = "All files (*.*)|*.*";
    if (openFileDialog1.ShowDialog() == DialogResult.OK)
        label1.Text = openFileDialog1.FileName;
}

14.3 SaveFileDialog

Lets the user choose a file name and location to save to.

SaveFileDialog sfd = new SaveFileDialog();
sfd.InitialDirectory = @"D:\";
sfd.Title = "Save Text File";
sfd.DefaultExt = "txt";
sfd.Filter = "Text files (*.txt)|*.txt|All files (*.*)|*.*";
if (sfd.ShowDialog() == DialogResult.OK)
    textBox1.Text = sfd.FileName;
Exam Trap: The dialogs only return a path; they do not open or save anything themselves. Filter syntax is pairs of Display Name|pattern joined by |.
Feature OpenFileDialog SaveFileDialog
Purpose Choose an existing file Choose a name/location to save
Key properties FileName, SafeFileName, Filter, Multiselect FileName, DefaultExt, Filter, OverwritePrompt

15. Event Wiring Under the Hood

When you double-click a button, Visual Studio writes a line in Form1.Designer.cs that subscribes your method to the event through a delegate (the Unit IV mechanism): 

// Auto-generated
this.btnShowName.Click += new System.EventHandler(this.btnShowName_Click);

// Your handler: must match EventHandler's signature
private void btnShowName_Click(object sender, EventArgs e)
{
    labelNameOut.Text = "Name: " + textBoxName.Text.Trim();
}

// One handler for many buttons, using sender
private void anyButton_Click(object sender, EventArgs e)
{
    Button clicked = (Button)sender;
    MessageBox.Show("You clicked: " + clicked.Text);
}
Key Concept: EventHandler is a built-in delegate with signature void (object sender, EventArgs e). sender = which control raised the event; e = extra event data.

17. Solved Problems

Problem 1: Delete confirmation with DialogResult

private void btnDelete_Click(object sender, EventArgs e)
{
    DialogResult choice = MessageBox.Show(
        "Are you sure you want to delete this record?",
        "Confirm Delete",
        MessageBoxButtons.YesNo,
        MessageBoxIcon.Warning);

    if (choice == DialogResult.Yes)
        MessageBox.Show("Record deleted.");
    else
        MessageBox.Show("Delete cancelled.");
}
  • Yes: returns DialogResult.Yes; "Record deleted." shows.
  • No: returns DialogResult.No; "Delete cancelled." shows and the delete code never runs.

Problem 2: OpenFileDialog filter and cancel path

OpenFileDialog ofd = new OpenFileDialog();
ofd.Filter = "Text Files (*.txt)|*.txt|CSV Files (*.csv)|*.csv|All Files (*.*)|*.*";
ofd.FilterIndex = 1;                          // .txt shown first
if (ofd.ShowDialog() == DialogResult.OK)
{
    textBoxPath.Text = ofd.FileName;
    MessageBox.Show("Selected: " + ofd.SafeFileName);
}
else MessageBox.Show("No file was selected.");
Outcome Result
User picks a .txt and clicks Open OK; full path in textbox; message shows only the file name
User clicks Cancel Cancel; else branch; textbox untouched
User switches the type to CSV Only .csv files listed; flow otherwise the same
