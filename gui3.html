1. Operators and Expressions

Core Concept

An operator is a symbol that performs an operation (+ - == &&); an operand is the value it works on; an expression is operands plus operators producing a value. Precedence decides evaluation order. 

// Arithmetic
int a = 10, b = 3;
a + b;   // 13
a - b;   // 7
a * b;   // 30
a / b;   // 3  (integer division)
a % b;   // 1  (remainder)

// Relational
5 > 8;  5 <= 8;  5 == 8;  5 != 8;     // False True False True

// Logical
int age = 20; bool hasId = true;
age >= 18 && hasId;   // True
age < 18 || hasId;    // True
!hasId;               // False

// Assignment
int n = 10; n += 5;   // 15
n *= 2;               // 30

// Increment / decrement
int p = 5; ++p;       // 6 (pre: increment, then use)
int q = 5; q++;       // gives 5, then q becomes 6 (post)

// Bitwise (a=0101, b=0011)
5 & 3;  // 1
5 | 3;  // 7
5 ^ 3;  // 6

// Ternary
string result = (70 >= 33) ? "Pass" : "Fail";   // Pass
Category Operators Result type
Arithmetic + - * / % number
Relational == != > < >= <= bool
Logical && || ! bool
Assignment = += -= *= /= value stored
Conditional ?: depends

Operator precedence (high to low)

 Unary (! ++ --)  >  Multiplicative (* / %)  >  Additive (+ -)
   >  Relational (< > <= >=)  >  Equality (== !=)  >  &&  >  ||  >  ?:  >  =

 10 + 5 * 2
   Step 1: 5 * 2 = 10     (* binds tighter than +)
   Step 2: 10 + 10 = 20
Exam Trap: 10 / 3 is 3 in C# (both operands int). Use 10.0 / 3 for 3.333.... Post-increment returns the old value.

2. Methods and Parameters

Core Concept

A method is a reusable block of code. A parameter is the variable in the definition; an argument is the actual value passed. C# supports value, ref, out, optional and params parameters. 

returnType MethodName(parameters)
{
    // statements
    return value;
}
// A) Value parameter (default: a copy is passed)
static int Add(int a, int b) { return a + b; }
Console.WriteLine(Add(5, 7));        // 12

// B) ref: pass by reference (variable must be initialized first)
static void Increase(ref int x) { x = x + 10; }
int n = 5;  Increase(ref n);         // n is 15

// C) out: returns multiple values (need not be initialized first)
static void GetStudent(out int id, out string name) { id = 101; name = "Amit"; }
GetStudent(out int sid, out string sname);

// D) Optional parameter (must come after required ones)
static void Greet(string name = "Guest") { Console.WriteLine("Hello " + name); }
Greet();          // Hello Guest
Greet("Ravi");    // Hello Ravi

// E) params: variable number of arguments (must be last)
static int Sum(params int[] nums)
{
    int s = 0;
    foreach (int v in nums) s += v;
    return s;
}
Sum(1, 2, 3, 4);                     // 10
Style Keyword Effect
Value (none) Copy passed; caller's variable unchanged
Reference ref Caller's variable modified; must be initialized before call
Output out Method must assign it; used to return several values
Optional = default Argument can be omitted
Variable count params Collects arguments into an array; only one, and last 
 Main() calls Add(5, 7)
    |
    v
 Control goes to Add(a=5, b=7)
    |
    v
 Compute a + b  =>  12
    |
    v
 Return 12 to Main()
Exam Trap: ref needs an initialized variable before the call; out does not, but the method must assign it before returning.

3. IF Statements

Decision making: a block runs only when the condition is true. C# has if, if-else, else-if ladders and nested if. 

int marks = 30;
if (marks >= 33) Console.WriteLine("Pass");
else             Console.WriteLine("Fail");        // Output: Fail

// else-if ladder
int m = 85;
if      (m >= 90) Console.WriteLine("A+");
else if (m >= 75) Console.WriteLine("A");          // Output: A
else if (m >= 60) Console.WriteLine("B");
else              Console.WriteLine("C");
         +-----------+
         | Condition?|
         +-----+-----+
          True |  | False
               v  v
      Execute IF   Execute ELSE
               \  /
                End
Exam Trap: The condition must be a bool. if (x = 5) is a compile error in C# (unlike C/C++).

4. switch-case Statements

A multi-way selection that compares one expression with constant values. Each case must end with break (C# forbids silent fall-through); default runs if nothing matches. 

int choice = 2;
switch (choice)
{
    case 1: Console.WriteLine("Add");    break;
    case 2: Console.WriteLine("Update"); break;   // Output: Update
    case 3: Console.WriteLine("Delete"); break;
    default: Console.WriteLine("Invalid"); break;
}
Exam Trap: In C# a non-empty case without break (or return/goto) is a compile error. Empty cases may stack for shared code.

5. Looping Statements

Loop Use
for Known iteration count
while Condition checked before each iteration
do-while Runs at least once; condition checked after
foreach Arrays and collections; read-only iteration variable 
for (int i = 1; i <= 5; i++) Console.WriteLine(i);

int j = 1;
while (j <= 5) { Console.WriteLine(j); j++; }

int k = 1;
do { Console.WriteLine(k); k++; } while (k <= 5);

int[] arr = {10, 20, 30};
foreach (int x in arr) Console.WriteLine(x);     // 10 20 30

break stops the loop; continue skips the current iteration.

Exam Trap: You cannot assign to a foreach iteration variable, and modifying the collection during foreach throws InvalidOperationException.

6. Arrays: 1D, 2D, Jagged, ArrayList, List<T>

An array stores multiple values of the same type under one name with zero-based indexing. 

// 1D
int[] marks = {70, 80, 90};
Console.WriteLine(marks[1]);          // 80

// Rectangular 2D
int[,] mat = { {1,2,3}, {4,5,6} };
Console.WriteLine(mat[1,2]);          // 6

// Jagged (array of arrays, rows can differ in length)
int[][] jag = new int[3][];
jag[0] = new int[] {1, 2};
jag[1] = new int[] {3, 4, 5};
jag[2] = new int[] {6};
Console.WriteLine(jag[1][2]);         // 5

// ArrayList (non-generic, not type-safe, boxes values)
ArrayList al = new ArrayList();
al.Add(10); al.Add("Hello"); al.Add(5.5);

// List<T> (generic, type-safe, recommended)
List<int> list = new List<int>();
list.Add(10); list.Add(20);
Feature Array ArrayList List<T>
Size Fixed Dynamic Dynamic
Type safety Yes No Yes
Performance High Lower (boxing) High
Use Fixed data Legacy code Modern best practice
Exam Trap: int[2,3] (rectangular) and int[2][] (jagged) are different. Out-of-range access throws IndexOutOfRangeException.

7. String Handling: string vs StringBuilder

Core Concept

string is immutable: any change creates a new object. StringBuilder (System.Text) is mutable and built for repeated modification. 

string s = "Hello";
s = s + " World";                  // creates a NEW string object

StringBuilder sb = new StringBuilder("Hello");
sb.Append(" World");
sb.Append("!");
Console.WriteLine(sb.ToString());  // Hello World!
Feature string StringBuilder
Mutability Immutable Mutable
Best for Small edits Many concatenations
Speed in a loop Slow Fast
Memory New object each time One resizable buffer 
string result = "";
for (int i = 0; i < 5; i++)
    result = result + i;           // 6 string objects: "", "0", "01", ... "01234"

StringBuilder sb2 = new StringBuilder();
for (int i = 0; i < 5; i++)
    sb2.Append(i);                 // same internal buffer
string final = sb2.ToString();     // one final string
Key Concept: In a loop of 100,000 iterations, string concatenation can create about 100,000 discarded objects for the GC; StringBuilder creates almost none.

8. Solved Problems

Problem 1: Evaluate a mixed expression

int a = 4, b = 2, c = 3;
bool result = a + b * c > 8 && !(a == b);
  1. !(a == b): 4 == 2 is False, so it is True.
  2. b * c = 6.
  3. a + 6 = 10.
  4. 10 > 8 = True.
  5. True && True = True.

Problem 2: Nested loop output

for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= i; j++)
        Console.Write(j);
    Console.WriteLine();
}
 i=1: j=1          -> 1
 i=2: j=1,2        -> 12
 i=3: j=1,2,3      -> 123
 Output:
 1
 12
 123

Problem 3: params + ref together

static void AddAll(ref int total, params int[] values)
{
    foreach (int v in values) total += v;
}
int total = 100;
AddAll(ref total, 5, 10, 15);
Console.WriteLine(total);     // 130

values becomes {5,10,15}; ref lets the method change the caller's total: 100 → 105 → 115 → 130.
