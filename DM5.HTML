1. Issues Regarding Classification and Prediction

Classification predicts categorical class labels; prediction models continuous values. Classification is a two-step process: learning (build model from training set with known labels) then classification (test set checks accuracy, then model labels new data). It is supervised learning.

  • Data preparation: cleaning, relevance analysis, normalization/generalization.
  • Evaluation criteria: accuracy, speed, robustness (noise, missing values), scalability, interpretability.

2. Classification by Decision Tree Induction

        [ age? ]
       /   |    \
   <=30  31-40  >40
    |      |      |
[student?] YES [credit?]
 /   \          /    \
no   yes    fair    excellent
NO   YES    YES      NO

Basic algorithm (ID3/C4.5): greedy, top-down, recursive divide-and-conquer. All tuples start at the root; choose the best attribute by an attribute selection measure; split; stop when all tuples are one class, no attributes remain (majority vote), or no tuples remain.

Measure Formula / idea
Information gain (ID3) Info(D) = −Σ pi log2 pi; Gain(A) = Info(D) − InfoA(D); pick max gain
Gain ratio (C4.5) Gain / SplitInfo; fixes bias toward many-valued attributes
Gini index (CART) Gini(D) = 1 − Σ pi²; pick min Gini; binary splits

Example: 9 yes, 5 no: Info(D) = −(9/14)log2(9/14) − (5/14)log2(5/14) = 0.940 bits.

  • Tree pruning: prepruning (halt early) and postpruning (cut a full tree) remove branches caused by noise/outliers and avoid overfitting.
  • Extract rules: one IF-THEN rule per root-to-leaf path.
Exam Trap: Information gain is biased toward attributes with many values (e.g. ID). Gain ratio corrects this; Gini is used by CART.

3. Bayesian Classification

Statistical classifier based on Bayes theorem: P(H|X) = P(X|H) · P(H) / P(X).

  • Naive Bayesian: assumes attributes are conditionally independent given the class: P(X|Ci) = Π P(xk|Ci). Assign X to the class with the highest P(X|Ci)·P(Ci).
  • Laplacian correction: add 1 to counts to avoid zero probabilities.
  • Bayesian belief networks: directed acyclic graph + conditional probability tables; allow dependencies among attributes.

4. Classification by Back-propagation

A neural network has an input layer, one or more hidden layers and an output layer; units are connected by weighted links. 

 Inputs x1..xn -> [Hidden layer] -> [Output layer] -> Class
 Unit: net = Σ wi·xi + bias ; output = 1 / (1 + e^-net)  (sigmoid)
 Forward pass -> compute error -> propagate error BACKWARD -> update weights
  • Weight update: w = w + (l)·Err·O, where l is the learning rate.
  • Pros: tolerates noisy data, handles continuous inputs. Cons: long training, hard to interpret, needs parameter tuning.

5. Classification Based on Association Rule Mining

Associative classification (CBA, CMAR, CPAR) mines class-association rules (conditions) ⇒ class using support and confidence, then builds a classifier from the best rules. Often more accurate than decision trees because it explores combinations of attributes.

6. Other Classification Methods and Prediction

Method Idea
k-Nearest Neighbour Lazy learner: majority class among k closest training tuples (Euclidean distance)
Case-based reasoning Stores cases; retrieves similar ones to solve new problems
Genetic algorithms Rules as bit strings; evolve using crossover and mutation
Rough set / fuzzy set Handle imprecise data; fuzzy membership values in [0,1]

Prediction uses regression: linear y = w0 + w1x (least squares), multiple regression, non-linear/polynomial, log-linear models.

7. Classifier Accuracy

Predicted Yes Predicted No
Actual Yes TP FN
Actual No FP TN
  • Accuracy = (TP+TN)/(P+N); Sensitivity = TP/P; Specificity = TN/N; Precision = TP/(TP+FP).
  • Estimation methods: holdout (2/3 train, 1/3 test), random subsampling, k-fold cross-validation, bootstrap. Boosting/bagging improve accuracy by combining classifiers.
