1. Cluster Analysis: Introduction

Clustering groups data objects so that objects in a cluster are similar to each other (high intra-class similarity) and dissimilar to other clusters (low inter-class similarity). It is unsupervised (no class labels). Applications: market segmentation, document grouping, image processing, pattern recognition.

Requirements: scalability, mixed attribute types, arbitrary shapes, minimal domain knowledge for parameters, noise tolerance, high dimensionality, interpretability.

2. Types of Data in Cluster Analysis

Type Handling
Interval-scaled Standardize (z-score); distance: Euclidean d=√Σ(xi−yi)², Manhattan Σ|xi−yi|, Minkowski
Binary Contingency table; symmetric: (b+c)/(a+b+c+d); asymmetric (Jaccard): (b+c)/(a+b+c)
Nominal d = (p−m)/p (m = number of matches)
Ordinal Replace by rank, normalize to [0,1], treat as interval-scaled
Ratio-scaled Apply log transform, then treat as interval-scaled
Mixed types Weighted combination of per-attribute dissimilarities

3. Categorization of Major Clustering Methods

Category Idea Examples
Partitioning Build k partitions, relocate objects iteratively k-means, k-medoids, CLARANS
Hierarchical Agglomerative (bottom-up) or divisive (top-down) tree BIRCH, CURE, Chameleon
Density-based Grow clusters while density exceeds threshold DBSCAN, OPTICS
Grid-based Quantize space into grid cells STING, CLIQUE
Model-based Fit data to a statistical/neural model EM, COBWEB, SOM

4. Partitioning Methods

k-Means

  1. Pick k objects as initial cluster centres.
  2. Assign each object to the nearest centre (mean).
  3. Recompute each cluster mean.
  4. Repeat 2-3 until no change. Criterion: minimize E = ΣΣ |p − mi|².

Example: points 2, 4, 10, 12, 3, 20, 30, 11, 25; k=2, initial centres 2 and 4 → C1={2,3}, C2={4,10,12,20,30,11,25} → means 2.5, 16 → C1={2,3,4,10}, C2={12,20,30,11,25} → means 4.75, 19.6 → C1={2,3,4,10,11,12}, C2={20,30,25} → means 7, 25 → stable.

k-Medoids (PAM)

Uses an actual object (medoid, the most central) as the centre; swaps medoids with non-medoids if it lowers total cost. More robust to outliers than k-means but costlier.

Exam Trap: k-means is sensitive to outliers (mean is pulled), needs k in advance and finds only spherical clusters; k-medoids reduces outlier sensitivity.

5. Density-Based Methods (DBSCAN)

Parameters: ε (neighbourhood radius) and MinPts.

Term Meaning
Core object Has ≥ MinPts objects within ε
Directly density-reachable q is within ε of core object p
Density-reachable Chain of directly density-reachable objects
Border point / Noise Within ε of a core but not core / belongs to no cluster

Pros: arbitrary-shape clusters, handles noise, no k needed. Cons: sensitive to ε and MinPts, struggles with varying density.

6. Outlier Analysis

An outlier deviates markedly from other objects (noise or genuine rare event). Used in fraud detection, intrusion detection, medical analysis.

Approach Idea
Statistical Assume a distribution; objects with low probability are outliers (discordancy tests)
Distance-based DB(p,D) outlier: at least fraction p of objects lie farther than D
Density-based Local outlier factor (LOF) compares local density to neighbours
Deviation-based Objects that deviate from the group's main characteristics

7. Mining Complex Types of Data

Data type Mining approach
Complex objects / multidimensional Generalize structured/object data, aggregate and approximate; multidimensional analysis and descriptive mining
Spatial databases Spatial data cubes, spatial association (near, adjacent), clustering, classification; e.g. houses near a lake
Multimedia databases Content-based retrieval (colour, texture, shape), similarity search, multidimensional and associations
Time-series and sequence data Trend analysis (trend, cycle, seasonal, random), similarity search, sequential pattern mining (e.g. buys PC then printer)
Text databases Information retrieval (precision/recall), keyword indexing (TF-IDF), text classification and clustering
World Wide Web Web content, web structure (links: PageRank, HITS) and web usage (logs, clickstream) mining
Key Concept: Web mining has three branches: content, structure and usage. Text retrieval quality: precision = relevant∩retrieved / retrieved; recall = relevant∩retrieved / relevant.
