Unit III: Concept Description

Unit III Map: Characterization & Comparison → Generalization (AOI) → Analytical characterization → Attribute relevance → Class comparison → Statistical measures.

1. Characterization and Comparison

Concept description produces a concise summary of a collection of data. Characterization summarizes the general features of a target class (e.g. profile of high-spending customers). Comparison (discrimination) contrasts the target class with one or more contrasting classes.

Concept description OLAP / statistics
Handles complex data types and attributes Mostly numeric dimensions and measures
Automated, generalizes dimensions itself User-driven, user picks dimensions

2. Data Generalization and Summarization-Based Characterization

Attribute-Oriented Induction (AOI) generalizes data from low to high concept levels using concept hierarchies.

  1. Data focusing: collect task-relevant data with a query.
  2. Attribute removal: drop an attribute with many distinct values and no hierarchy.
  3. Attribute generalization: replace values by higher-level concepts (city → country) when a hierarchy exists.
  4. Attribute generalization threshold: stop when distinct values ≤ threshold (typically 2-8).
  5. Aggregation: merge identical tuples and accumulate count.
  6. Presentation: generalized relation, cross-tab, or rules with t-weight. 
 Name  Major   Birthplace    GPA           Name removed; Major -> Science;
 Ann   CS      Dehradun   -> 3.7       ->  Birthplace -> India; GPA -> Excellent
 Raj   Math    Pune          3.8           => (Science, India, Excellent) count=2
Exam Trap: Two thresholds exist: the attribute threshold (distinct values per attribute) and the relation threshold (maximum tuples in the final relation).

Presentation: t-weight = count(q) / Σ count(q_i) shows how representative a tuple is of its class. Output forms: generalized relation, cross-tabulation, bar/pie charts, 3-D cubes, and characteristic rules.

3. Analytical Characterization: Analysis of Attribute Relevance

Used when there are many attributes: first remove irrelevant ones, then characterize. Measures of relevance: information gain, Gini index, uncertainty coefficient, correlation.

Information Gain Method

  • I(s1,s2) = − Σ pi log2(pi) : expected information for classification.
  • E(A) = Σ [(s1j+s2j)/s] · I(s1j,s2j) : entropy after splitting on attribute A.
  • Gain(A) = I(s1,s2) − E(A) : higher gain = more relevant.

Steps: data collection → preliminary relevance analysis (conservative; drop weak attributes) → remove irrelevant attributes → AOI on the rest.

4. Mining Class Comparisons: Discriminating between Classes

Compares target and contrasting classes that share the same attributes and dimensions.

  1. Data collection (target and contrasting classes).
  2. Dimension relevance analysis.
  3. Synchronous generalization of both classes to the same level.
  4. Presentation of the comparison (tables, graphs, rules).
Rule type Meaning
Characteristic rule Properties common to the target class
Discriminant rule Properties that distinguish the target class from contrasting ones

d-weight = count(target tuple) / Σ count over all classes: how well a tuple discriminates the target from the others.

5. Mining Descriptive Statistical Measures in Large Databases

Type Measures
Central tendency Mean (distributive/algebraic), weighted mean, median (holistic), mode, midrange
Dispersion Range, quartiles Q1/Q3, IQR = Q3 − Q1, variance, standard deviation
Five-number summary Min, Q1, Median, Q3, Max (shown as a boxplot)
  • Empirical relation: mean − mode ≈ 3 × (mean − median) for moderately skewed data.
  • Outlier rule: value below Q1 − 1.5×IQR or above Q3 + 1.5×IQR.
  • Graphs: histogram, quantile plot, Q-Q plot, scatter plot, loess curve.
Key Concept: In large databases compute measures incrementally: sum/count/min/max can be merged from partitions; median needs approximation.
